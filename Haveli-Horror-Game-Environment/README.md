# 🏚️ Haveli Horror Game Environment

My first major Blender project after learning the fundamentals of 3D modeling.

This project is an Indian-inspired Haveli environment that I am developing as a map for a horror game I would like to create.

The current version focuses on building the main architecture and overall layout of the environment. The project is still under development and will gradually be expanded with more details, props, materials, lighting, and gameplay-focused elements.

## Current Features

* Central courtyard
* Main Haveli structure
* Rooms and corridors
* Roof structure
* Stairs and elevated areas
* Decorative railings
* Doors and windows
* Exterior areas
* Basic environment layout

## Planned Development

* More detailed architecture
* Additional rooms and areas
* Furniture and environmental props
* Materials and textures
* Horror-themed environmental details
* Lighting and atmosphere
* Optimization for game use
* Integration into Unity

## Software

* Blender
* Unity *(planned)*

## Status

🟡 **Work in Progress — ~25–30%**
